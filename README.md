# Kindle Rebirth Dashboard

A free, low-power information dashboard for Kindle Paperwhite 3.

- Weather: Shanghai Pudong and Guildford, Surrey
- Clocks: Shanghai, Los Angeles and London
- Calendar: iCloud ICS through an encrypted GitHub Actions secret
- Notes: edit `dashboard/notes.md`
- Output: 1072×1448 8-bit grayscale PNG

See [`dashboard/README.md`](dashboard/README.md) for setup and maintenance details.
